## Planning an industrial indoor positioning system

### What is a real-time location system (RTLS)?

An RTLS connects tracked objects, radio observations and a location engine to keep a current view of people or assets. For industrial indoor positioning, start with the required zones or coordinates, then select compatible tags, gateways and software interfaces.

[Compare indoor positioning technologies](https://www.rpilink.com/solutions/)

### Which hardware fits personnel and asset tracking?

Personnel badges and helmet terminals suit people; asset tags suit tools and equipment. Match Bluetooth, AoA or UWB capabilities to the receiving stations, update requirements and installation environment.
